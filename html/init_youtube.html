# 🎬 YouTube Clone A front-end YouTube-style webpage built using **HTML and CSS**. This project recreates the basic layout of YouTube, including the header, search bar, sidebar navigation, video thumbnails, channel information, and responsive video grid. ## 📌 Project Purpose The purpose of this project is to practice and demonstrate fundamental **HTML and CSS** skills by recreating a familiar video-sharing website interface. ## 🚀 Features - YouTube-style header - Hamburger menu and YouTube logo - Search bar - Voice search button - Create/upload button - YouTube apps icon - Notification icon with notification count - User profile image - Sidebar navigation - Video thumbnail grid - Video duration labels - Channel profile pictures - Video titles - Channel names - Video views and upload dates - CSS tooltips ## 🛠️ Technologies Used - HTML5 - CSS3 - CSS Grid - CSS Flexbox - Google Fonts - SVG icons - WebP/AVIF images ## 📂 Project Structure ```text youtube-clone/ │ ├── index.html │ ├── styles/ │ ├── video.css │ ├── header.css │ ├── general.css │ └── sidebar.css │ ├── icon/ │ ├── hamburger-menu.svg │ ├── youtube-logo.svg │ ├── search.svg │ ├── voice-search-icon.svg │ ├── upload.svg │ ├── youtube-apps.svg │ └── notifications.svg │ ├── sidebar/ │ ├── home.svg │ ├── explore.svg │ ├── subscriptions.svg │ ├── originals.svg │ ├── youtube-music.svg │ └── library.svg │ ├── thumbnail/ │ ├── thumbnail-2.webp │ ├── thumbnail-3.webp │ ├── thumbnail-4.webp │ ├── thumbnail-5.webp │ └── thumbnail-6.webp │ └── channel-profile/ ├── channel-1.jpeg ├── channel-2.jpeg ├── channel-3.jpeg ├── channel-4.jpeg ├── channel-5.jpeg └── channel-6.jpeg youtube clone
