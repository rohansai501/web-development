

 ### 🌐 Web Development — YouTube Clone

 > **A front-end YouTube-style clone developed using HTML5 and CSS3. This project focuses on recreating the YouTube interface through structured layouts, CSS Grid, Flexbox, navigation components, video thumbnails, channel information, search UI, tooltips, and responsive design.**

 ### Skills demonstrated

 - **HTML5** — Page structure and semantic elements
- **CSS3** — Styling and layout
- **CSS Grid** — Video grid layout
- **Flexbox** — Header and component alignment
- **Responsive Web Design** — Adapting layouts to different screen sizes
- **CSS Positioning** — Header, sidebar, and video elements
- **Google Fonts** — Roboto typography
- **SVG Icons** — Interface icons
- **File Organization** — Separate HTML, CSS, images, and icons
